# Claude Skills

A collection of custom Claude skills for enhanced productivity.

## Skills

### make-notes
Captures web page content tailored for experienced frontend developers. Creates technical notes with:
- Key architectural decisions and design patterns
- Performance implications and browser compatibility
- Code analysis and modern alternatives  
- Gotchas, edge cases, and best practices
- Integration notes for modern tooling (Webpack, Vite, React, Vue, etc.)
- Diagrams and architecture visuals

**Best for:** Technical blog posts, documentation, performance guides, architecture articles, RFCs

**How to use:** "Make notes on this page" – automatically extracts and saves to Notion

## Installation

These skills are designed to work with Claude. Each skill is a SKILL.md file that can be imported into your Claude workspace.
